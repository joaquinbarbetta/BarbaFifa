# BarbaFifa
Barba Fifa es la app definitiva para tu juntada de FIFA con amigos. Llevá un registro completo de cada partido y convertí esas tardes de PlayStation en una verdadera competencia:

🏆 Liga: tabla de posiciones automática con puntos, diferencia de gol y un historial completo de cada cruce
🥊 Copa: armá torneos eliminatorios de 4 u 8 jugadores con bracket en vivo
⚽ Bota de Oro: ranking de los goleadores virtuales (Mbappé, Haaland, o quien sea que metas con cada jugador)
🎲 Equipos: sorteá equipos al azar entre selecciones y clubes top de las grandes ligas, ideal para resolver discusiones de "con quién juego"
🏅 Logros: medallas automáticas como Goleador Despiadado, Muro de Berlín o El Cliente Frecuente
🎰 Ruleta del castigo: para el que pierde feo
Funciona 100% sin conexión, guarda todo localmente, y se puede instalar como app nativa desde el navegador. Hecha para que tu grupo nunca más discuta quién es el mejor.
